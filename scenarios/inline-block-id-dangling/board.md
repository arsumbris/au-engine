edges:
  - from: "[[^^root]]"
    to: "[[^^ghost]]"
---

The second endpoint names a block-id no record or marker carries.
`^^` demanded the block's value, so an absent id is `block-id-not-found`, an
error — not the navigational warning a bare `^` would give.
